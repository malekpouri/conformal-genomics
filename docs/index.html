How it works

Marginal coverage (split-conformal)

Any predictor is wrapped for finite-sample, distribution-free coverage under exchangeability:

$$1-\alpha \le \Pr(y\in C(x)) \le 1-\alpha+\tfrac{1}{n+1}.$$

A multi-objective $\infty$-norm score covers both objectives with one quantile (no union bound).

cfBH selective FAR control

Scalar target $T(y)=\min\{(y_{\mathrm{eff}}-\tau_{\mathrm{eff}})/s_{\mathrm{eff}},\,(\log(1{+}\tau_{\mathrm{off}})-\log(1{+}y_{\mathrm{off}}))/s_{\mathrm{off}}\}$, monotone score $V(x,t)=t-\hat T(x)$, full-calibration p-values + Benjamini–Hochberg:

$$p_j=\frac{1+\sum_{i=1}^{n}\mathbb{1}\{V(X_i,T_i)\le V(X_j,0)\}}{n+1}.$$

Controls the False Acceptance Rate (an FDR-type criterion) at $\mathrm{FAR}\le q$ in finite samples.

Supporting evidence

Real generator + coverage at scale

  • • Char-level autoregressive GRU trained on 55,603 real spacers → 100% novel, 100% unique candidates.
  • • Marginal coverage exact at 55k scale (0.899–0.900 at nominal 0.90).
  • • No leakage inflation: grouped-split coverage 0.903 vs random 0.901.

Beats real ML uncertainty baselines

Honest limits (what does not work)

Efficacy noise floor

Indel-efficacy is intrinsically hard: even at 55k the efficacy oracle tops out at Spearman ≤ 0.78, below the ≳ 0.9 fidelity cfBH needs. Efficacy-only and joint selection power are ≈ 0 — a property of the assay, not of conformal prediction. More data does not help.

Coverage does not transfer

No cohort carries both validated efficacy and validated off-target, so the multi-objective guarantee is validated per objective, never jointly. Recalibrate per nuclease/cell-line rather than assuming transfer.

Quickstart

Install & reproduce (CPU)
git clone https://github.com/malekpouri/conformal-genomics.git
cd conformal-genomics
pip install -r requirements.txt
./reproduce.sh   # pipeline + remediation + 38 tests
Off-target safety selection with FAR control
from src.selection import ConformalSelector

sel = ConformalSelector(tau_eff=45., tau_off=20.)\
        .fit(train_seq, train_eff, train_off)
sel.calibrate(cal_seq, cal_eff, cal_off)
# FAR <= q, plus power / precision / yield
print(sel.evaluate(test_seq, test_eff, test_off, q=0.10))
